# Что необходимо для использования бота:

------------

- Создать бота и получить API токен у [@BotFather](https://t.me/botfather)
- Создать Telegram приложение на [сайте](https://my.telegram.org/auth), взять токен и хеш код.


> Для использования команд, предназначеных для админа, необходимо указать его id в .env файле. Чтобы получить id можно использовать команду `/getuserid`, она доступна всем пользователям в личном чате с ботом.
